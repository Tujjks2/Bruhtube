# BruhTube — видеохостинг, стартовая версия

Адаптивный сайт видеоплатформы: каталог, категории, поиск, просмотр видео, авторизация и публикация роликов через Supabase Storage.

## Запуск локально
В папке проекта выполни:
```bash
python -m http.server 8000
```
Открой http://localhost:8000. Для демонстрации доступны тестовые карточки и тестовый ролик в плеере.

## Подключение Supabase
1. Создай проект на https://supabase.com/.
2. Открой SQL Editor → New query и выполни весь файл `supabase.sql`.
3. В Project Settings → API скопируй Project URL и anon/public key.
4. Вставь их в `supabase-config.js` в поля `url` и `anonKey`.
5. В Authentication → URL Configuration добавь URL локального сайта и адрес GitHub Pages в Redirect URLs.
6. В Authentication настрой подтверждение email по своему желанию.

Важно: используй только anon/public key в клиентском коде. Никогда не вставляй service_role key.

## Публикация на GitHub Pages
1. Создай репозиторий, например `BruhTube`.
2. Загрузи в корень репозитория `index.html`, `styles.css`, `app.js`, `supabase-config.js`, `supabase.sql`, `README.md`.
3. Открой Settings → Pages.
4. В Build and deployment выбери Deploy from a branch.
5. Выбери ветку `main` и папку `/ (root)`, затем Save.
6. Сайт появится по адресу `https://ТВОЙ-ЛОГИН.github.io/BruhTube/`.

## Что уже есть
- Адаптивный интерфейс для телефона и ПК.
- Поиск по заголовку, описанию и каналу.
- Категории видео.
- Просмотр в HTML5-плеере и блок похожих видео.
- Регистрация и вход через Supabase Auth.
- Загрузка видео в публичный Supabase Storage bucket и сохранение метаданных в таблице `videos`.

## Ограничения этой версии
Это стартовый видеохостинг, не копия инфраструктуры YouTube. Комментарии, реальные лайки с сервера, подписки, модерация, рекомендации и потоковая обработка больших видео ещё не реализованы. Публичный bucket означает, что опубликованные видео доступны по прямой ссылке. GitHub Pages обслуживает только статические файлы и не является сервером обработки видео. Для открытого запуска нужны лимиты загрузок, модерация, жалобы, правила сообщества и защита от злоупотреблений.
